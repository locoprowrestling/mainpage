LoCo Pro Wrestling main page
----------------------------

- `index.html` is the root landing page for the LoCo Pro Wrestling web presence.
- GitHub Pages deploys via `.github/workflows/deploy-pages.yml`.
- The publish artifact is prepared by `scripts/build-pages.sh`.
- Assumption: this repo is intended for the apex domain `locopro.pw`, so `CNAME` is set accordingly.
- Note: the 2017 event site should use `mainstreet.locopro.pw`.
